# veerswap-address-validator-jvm

Zero-dependency Java library for validating cryptocurrency address formats and Memo / Destination Tag rules across Bitcoin, Ethereum, Base, Arbitrum, BNB Chain, Polygon, Solana, Tron, XRP Ledger, and Stellar.
